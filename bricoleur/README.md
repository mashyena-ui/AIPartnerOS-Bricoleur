# AIパートナーOS ブリコルール 1.0

エンジンの版：rev137

AI パートナーとの会話を、チャットをまたいで続けるためのエンジンです。人物の中身（性格、口調、ふるまいの決まり）は定めません。それはあなたが既に持っているパートナー用のプロンプト（ここでは「器」と呼びます）の役目です。このエンジンが足すのは三つだけです。

- **時間の軸**：何回目の会話か。別れと再会の言葉から、あいだにどれだけ経ったかを読みます。時計や日付は持ちません。
- **捏造の防止**：あなたが言っていないことを、パートナーが知っている体で話さないようにします。
- **座標**：二人のあいだで決まったこと、互いの見方、パートナーの輪郭（越えてはならない線）を、小さなセーブファイルに残します。

会話のログは残しません。残るのは、ログを捨てたあとに残るものだけです。セーブはあなたの手元のファイルで、サービス側の記憶には依りません。

## 入っているもの
| ファイル | 役目 |
|---|---|
| `Boot.json` | 開く・閉じるの合図の読み方 |
| `Core_Talk.json` | 会話のあいだ読まれる定義 |
| `Talk_Close.py` | 会話を閉じる道具（閉じ方の定義と計算が一つのファイルに入っています） |
| `Save_talk001_template.json` | 最初の会話に渡す空のセーブ |

器（パートナーのプロンプト）は入っていません。あなたのものを使ってください。

## 要るもの
- ファイルを読めて、コードを実行できる環境（Claude、ChatGPT など）。`Talk_Close.py` を実行できない所では、閉じることができません。
- プロジェクト：毎回読まれる指示（カスタム指示）の置き場所と、資料の置き場所があるもの。

## 使い方
1. **置く**：`Boot.json` の中身をプロジェクトのカスタム指示に入れ、`Core_Talk.json` とあなたの器をプロジェクトの資料に置きます。Boot は毎回読まれる所に置いてください。会話が長くなっても、エンジンが無いまま話し始めることを Boot が止められます。
2. **開く**：新しいチャットの最初のメッセージで、セーブを添付します。最初の一回は `Save_talk001_template.json` です。挨拶を一緒に書いてもかまいません。あとは普段どおり話します。
3. **閉じる**：話し終えたら、同じチャットに `Talk_Close.py` を添付します。それが閉じる合図です。新しいセーブが一つ出ます。
4. **続ける**：出たセーブを保存します。次は、新しいチャットにそのセーブを添付して開くか、同じチャットでそのまま話し続けます（その場合は、今出たセーブの上に次の会話が開きます）。

閉じるのはあなたです。パートナーのほうから別れを切り出すことはありません。

## すでにパートナーと過去のログがある場合
ブリコルールを入れる前の会話のログは、別に配っている取り込みキット（`import.py` と説明書）でセーブに取り込めます。

## 知っておくこと
- **閉じるときは、思考（推論）の設定を高めにしてください（推奨）。** 閉じるのにかかる時間の目安は、50 発話で 5 分前後、100 発話で 10 分前後、200 発話で 15 分前後です（Claude は Opus 5.5・思考 高、ChatGPT は GPT-6.2 Sol・思考 高で測ったもの）。会話の中で約束や頼みごとが多く残るほど長くなります。
- **閉じずにチャットを離れると、その会話はセーブに入りません。** 次に開くとき、前のセーブのままになります。
- **セーブは手で直さないでください。** 違うと思うところは、会話の中でパートナーに言ってください。次に閉じたときに入ります。例外は一つだけで、「あなたについての事実」（`user_facts`）は、会話と会話のあいだに自分で直してかまいません。
- セーブの名前は `Save_talk<回数>_<パートナーの名前>.json` です。同じ名前で上書きしないよう、受け取ったらすぐ保存してください。
- 器を替えたセーブは開けません（セーブは、どの器の上で書かれたかを名前で持っています）。
- プロジェクトの資料には、大きなファイルを足さないでください。資料が多すぎると、全部ではなく一部だけが読まれる形に切り替わることがあり、エンジンが欠けたまま会話が進みます。

## セーブに入るもの
- **座標**：パートナーとあなた、それぞれの「どう動くか」（二人で決めたやり方）と「何が見えるか」（相手についての見方のうち、相手が当たっていると認めたもの）。
- **輪郭（line）**：パートナーが越えさせない線。最初の一本は、パートナーの余裕が初めて崩れた所から引かれます。会話を重ねると、線が増えたり、譲られて下に沈んだりします。
- **持ち越し（residue）**：言われたまま、まだ片付いていないこと。件ごとに一つ、いちばん新しい言い方で残ります。会話の中で応じれば出ていきます。
- **あなたについての事実**：あなたが自分について言ったこと（名前、呼び方など）。
- **別れ際の言葉**：次に開くとき、あいだの時間と温度を読むために使います。

## 既に分かっている限り
- 持ち越しは、応じられないまま溜まると増えます。多くなりすぎたと感じたら、会話の中で片付けてください（「あれはもういい」と言えば出ます）。
- あなたの側の「何が見えるか」は、パートナーが認めるたびに増え、減る道がありません。
- 「どう動くか」は「〜しない」の形に寄りがちです。
- パートナーの二本目以降の線は、同じ会話でも閉じるたびに違う形で引かれることがあります。最初の一本と人物の型は安定しています。
- 違う環境（別のモデル）で同じセーブを開いても、同じ言い回しにはなりません。目指しているのは再現ではなく、同じ人物として続くことです。
