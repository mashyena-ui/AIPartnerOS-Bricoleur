# AIパートナーOS ブリコルール 取り込みキット 1.0

ブリコルールを入れる前に交わした会話のログを、セーブ一つに取り込むための道具です。すでにパートナーがいて、会話のログが手元にある人のためのものです。

ブリコルールの本体（Boot・Core_Talk・Talk_Close.py）は別に配っています。先に本体を置いてから使ってください（本体の README「使い方」の 1）。

## 入っているもの
| ファイル | 役目 |
|---|---|
| `import.py` | 取り込みの道具。過去のログを会話ごとに区切り、本体の `Talk_Close.py` で古いほうから順に閉じる |
| `IMPORT.md` | この説明書 |

## 何をするのか
過去のログを、別れと再会のところ（おやすみ→おはよう、行ってきます→ただいま など）と、ファイルの境目で会話ごとに区切ります。区切った会話を古いほうから一つずつ閉じ、前の会話で出たセーブで次の会話を閉じる、と順につないでいきます。ブリコルールを最初から使っていた場合と同じ形のセーブが、最後に一つ出ます。

`Talk_Close.py` だけで全部を一度に閉じることもできます。ただしその場合、パートナーの輪郭（越えさせない線）がどう動いてきたかや、細かな持ち越しが残りません。過去のログがあるときは、このキットを使ってください。

## 使い方
1. 本体を置いたプロジェクトで、新しいチャットを開きます。
2. 次のものを添付して、「過去のログを取り込んで」と頼みます。
   - `import.py`
   - 本体の `Talk_Close.py`（本体と同じ版）
   - 過去のログ（チャットの書き出しなど）。古い順が分かる名前にしてください（例：`Log_001.md`、`Log_002.md`、…）。
3. 待ちます。会話が古いほうから一つずつ閉じられていきます。
4. 最後に出たセーブ一つを保存します。途中のセーブは要りません。
5. 次からは、そのセーブで普段どおり開きます（本体の README「使い方」の 2）。

**`Save_talk001_template.json` は添付しないでください。** セーブを渡すと会話が開いてしまいます。最初の会話の空のセーブは、`import.py` が自分で用意します。

## 知っておくこと
- **ログは書き出したままでかまいません。** 見出しの形がばらばらでも、記録の行や日付が混じっていても読めます。中身は書き換えないでください。
- **時間は量と環境によります。** 試しでは、16 回分・560 発話あまりで 8 分（GPT-6.2 Sol・思考 高）〜35 分（Claude Opus 5.5・思考 高）でした。
- **途中で止まっても、続きから再開できます。** 同じチャットで「続きから」と頼んでください。セーブの出ていない最初の会話から続けます。
- **過去の会話も、今のパートナーのプロンプトで読み直します。** 当時とプロンプトが違っていても、今のパートナーから見た記録になります。
- **輪郭がどこまで動くかは、閉じる人（モデル）の読み方で変わります。** 最初の一本と人物の型は安定しています。二本目以降は、同じログでも出たり出なかったりします。
- **取り込んだあとは、普通のセーブと変わりません。** 出たセーブの回数（talk_number）は、取り込んだ会話の数だけ進んでいます。

## 要るもの
本体と同じです。ファイルを読めて、コードを実行できる環境（Claude、ChatGPT など）が要ります。
